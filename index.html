01

准备：下载 & 登录

开始之前，先把安装包下载好、把订阅链接拿到手。

1

下载安装包

安装不做教程，安装软件很简单，直接默认安装即可。

打开下载地址

2

获取订阅链接

会直接发给你专属订阅链接。保留好，后面每一步都要用到。

3

生成订阅二维码

Shadowrocket 需要二维码，可自行找网站把链接生成二维码；Clash Verge 订阅后也支持直接生成「订阅二维码」。

02

桌面端：Clash Verge 配置订阅

Windows 与 macOS 的操作完全一致，照着下面四步走即可。

1

启动软件

找到 Clash Verge 双击启动。启动后有可能不会直接显示程序界面，手动点开图标进入仪表盘即可。

2

添加订阅

拿到专属订阅链接后，在 Clash Verge 中添加订阅。

3

设置选项

点击「设置」选项进行配置，把打勾的都打开。

4

全部完成 ✅

到此，全部完成。你的代理可以正常使用了。

小提醒 🔑

如果一开始不会、不研究，后期梯子出现各种问题该怎么办？——靠自己，从一开始就学会排查。支持付费配置 30¥/次（不推荐）。

03

iPhone：Shadowrocket 配置订阅

苹果手机相对简单，三步完成扫码订阅并开启代理。

1

打开 Shadowrocket

打开软件后，点击左上角的扫码按钮。

2

登录订阅网站

推荐：Clash Verge 订阅后直接生成「订阅二维码」。也可以拿订阅链接到 goqr.me 生成二维码。

3

开启代理

扫码之后，点击「未连接」的按钮，即可打开代理。

04

安卓：Clash for Android 教程

订阅链接已经直接发给你，按下面七步配置并开启连接。

配置流程
  • 收到订阅链接
  • 打开配置
  • 新建配置
  • 从 URL 导入
  • 填写名称与链接
  • 选中并返回
  • 开启连接
01

收到订阅链接

订阅链接已经直接发给你，后面从 URL 导入时粘贴即可。

02

打开配置

手机上打开 Clash，选择「配置」。

03

新建配置

选择「+ 新配置」。

04

从 URL 导入

选择「从 URL 导入」。

05

填写名称与链接

名称不用叫 igg，直接改成 bornforthis；链接就是订阅网站复制的；自动更新随意，推荐手动更新。

06

选中并返回

选中 bornforthis，然后返回。

07

开启连接

点击「已停止」按钮开启 VPN 连接，显示运行中就代表连接成功。

常见问题 · 必看

先把通用公告读一遍，遇到访问异常再对照排查。

  • 开启代理：更新完记得开代理。有人更新完了没开代理，却说不能用。
  • 代理不需要特意关闭，除非访问国内某些网站不能正常使用，不然可以一直挂着。
  • 这个 🪜 我也在用，有问题我会第一时间解决，其余请自行排查网络相关。
  • 所有节点都 timeout 时，先考虑手动更新代理订阅。如果点击手动刷新后显示失败，八成是网络问题或订阅到期。刷新成功后还都 timeout，再考虑自己的网络问题。
    • 不要觉得手动更新麻烦，我自己也在用梯子，速率慢或失效都会第一时间维护；因为是不定期维护，所以不能用时请手动刷新（保证高可用的根本）。
    • 如果手动更新失败，先把代理关闭再尝试更新（前提是梯子没过期）。本地代理失效时，用失效的代理去请求更新，有时仍会失败。
  • Apple Store 更换 ID 教程：点此查看。更换完成后自行安装 Shadowrocket，它是 iOS 平台相对稳定且更新多年的 App，支持协议众多。
  • 如果遇到某些网站无法访问——首先说明：绝不可能是代理问题。自行切换节点测试，切换前先点击测速按钮；并与当前宽带（品牌、速率、设备）及地区相关，推荐直接使用中国电信。

操作类教程

针对 Windows 系统代理、客户端更新和 Mac 自启的补充说明。

1

Windows 11 如何关闭代理服务器

如果出现网络问题，推荐手动关闭 Windows 的代理后，再手动开关一次 Clash Verge 的系统代理。其它 Windows 系统操作一致。

到这一步，就可以再次去手动开关一次系统代理。

2

客户端软件更新

Clash Verge 支持直接更新，注意需要在代理打开的情况下进行，默认一步步安装即可。如果直接更新失败，在正常使用代理的情况下，可自行去 GitHub 下载最新版覆盖安装。

3

Mac 开机自启问题

Mac 电脑中，如果 Clash 设置了开机自启，有时重启或开机后 Clash 会弹出如下窗口：

不要点击 Reopen，要点击 Don't Reopen，然后自己点开软件正常启动即可。
